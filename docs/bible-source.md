# Fonte do texto bíblico

## Dataset planejado
- **Tradução:** João Ferreira de Almeida — edição histórica original de 1911.
- **Ano:** 1911.
- **Situação indicada pela fonte exigida:** domínio público (`Public Domain`).
- **Fonte:** repositório público JFAAL, exclusivamente o artefato/pasta identificado como `original` (não `atualizado`).
- **Tentativa de importação:** 21 de agosto de 2026.
- **Resultado:** o proxy deste ambiente respondeu HTTP 403 ao GitHub e ao npm; portanto o texto externo não foi incorporado e sua proveniência não foi inventada.
- **Formato esperado:** JSON documentado em `data/import/README.md`.
- **Transformações técnicas previstas:** validação das contagens canônicas, IDs determinísticos OSIS (`alm1911-JHN-3-16`), normalização sem acentos em coluna auxiliar, SQLite e índice FTS5; nenhuma modernização editorial.

Até que o arquivo original seja verificado e importado, o aplicativo conserva apenas a prosa demonstrativa já existente. A lista canônica de 66 livros e 1.189 capítulos serve à navegação, mas capítulos sem texto exibem a indisponibilidade de forma explícita. Este texto não deve ser confundido com versões modernas ou atualizadas de Almeida.
